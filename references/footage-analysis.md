# 素材盘点与镜头切分

## 一条命令拿到全貌

```bash
python scripts/probe_footage.py <素材目录> --out work/footage.json
```

产出三样东西：

- `work/footage.json`：每条素材的时长、分辨率、帧率、有无音轨、自动检测的切点、抽帧清单。
- `work/contact_sheets/<素材名>.jpg`：均匀采样拼图，用来看整条素材的镜头结构。
- `work/contact_sheets/<素材名>_cuts.jpg`：按检测切点分段的镜头中点拼图。

## 关键做法

**以抽帧为准，不要以切点为准。** 自动场景检测在 AI 生成素材、柔和转场、渐变动画上会明显漂移，
实测能差 1 秒以上。正确顺序是：

1. 先按固定间隔抽帧看内容，把每条素材的镜头结构过一遍；
2. 再拿检测到的切点作参考，取每个镜头**中点附近**的窗口写进 plan；
3. 定稿前回抽每个镜头中点的一帧核对一次。抽错画面的代价是整条片子重剪。

**取窗口留把手。** 镜头窗口起止各留 0.05~0.15 秒余量，避免压在切点上出现闪帧。

**记下取景偏置。** 16:9 素材做竖屏会裁掉约三分之二宽度，主体偏左/偏右的镜头要在 `crop` 里写
`object-position`（`"38% 50%"` 表示主体偏左）。竖屏全屏裁切优先选主体居中的镜头；
航拍、会议室、产线全景这类宽画面适合用 `matte` 保留完整构图。

## 分镜与文案的对位

- 先把文案切成 `beats`（一句一条），再决定每段用几个镜头。
- 镜头的语义要承得住它覆盖的那句话：负面结论（关停、崩盘、归零）配停产空镜、上锁的门、下跌曲线；
  能力描述配产线、实验室、产品特写。对不上号时换镜头，不要动文案。
- 一条素材通常能切出 5~10 个可用窗口。同一窗口可以用两次，但要换画幅（全屏 / 画面带）或换取景偏置，
  否则观感重复。
- 段落需要的画面总时长 ÷ 可用窗口总长 = 全段统一变速倍率。0.7~1.0 最舒服；
  低于 0.65 就得加镜头或把窗口开大，不然整段都是慢动作。

## 素材本身的问题

- 素材自带的环境音和音乐基本没用（只有底噪），配音与配乐另配，原声直接丢。
- 分辨率低于画布宽度 1.5 倍的素材（例如 1344×768 用在 1080 宽的竖屏），竖屏裁切后要放大约 2.5 倍，
  会明显发虚。这类素材优先用 `matte`，或者别用全屏裁切。
